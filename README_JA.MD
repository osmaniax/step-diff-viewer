## 【Androidベータ版公開】3D CAD（STEP）ビューワ「STEP DIFF VIEWER」をベータリリースします


### STEP DIFF VIEWERとは？
Androidスマートフォン上でSTEPファイルを読み込み、加工前後など2つの3D形状を比較できる軽量ビューアです。

今回公開した「STEP DIFF VIEWER」の操作画面です。

目指したのは、高機能なCADソフトの代替ではありません。

「PCでCADソフトを立ち上げるほどではない。でも、手元ですぐ形状を確認したい」

そんな場面で使える、小さなツールです。

### STEP DIFF VIEWでできること
基本機能はかなりシンプルです。

#### Before

加工前など、比較元となるSTEPモデルを表示します。

#### Diff Overlay
![画面イメージ](./img/Screenshot_20260811-212336.png)

2つのSTEPモデルを色分けして重ね合わせ、形状の違いを視覚的に確認します。

ここは重要なのですが、厳密な幾何差分を計算して「削られた領域」を算出しているわけではありません。

2つの形状を同一座標系上で重畳表示することで、

「どこが変わったのか」

を直感的に確認するための機能です。

### 新機能：形状解析と推奨加工工程

STEPモデル単体から、外形寸法、概算体積、主要な穴径を確認できる「形状解析」を追加しました。

- ドリル穴、貫通穴、座ぐり・段付き穴を識別して3Dモデル上に表示
- 検出した径と深さから推定除去体積を求め、穴加工の依存関係を考慮した推奨加工順を表示
- 各工程に推奨工具を表示
- 穴ラベルと左上の工程一覧を相互に選択可能
- 断面表示はX・Y・Z軸と切断位置を選択可能

推奨加工工程と工具は、STEP形状から推定した参考情報です。材質、工作機械、保持方法、切削条件、CAMツールパスは考慮していません。また、外径旋削、端面加工、外径仕上げ用工具は現在の推奨工程に含まれません。

### 形状解析の使い方

1. 上部の「形状解析」を選択します。
2. STEPファイルを選ぶか、デモデータを読み込みます。
3. 「寸法・穴径」をタップすると、検出した穴のラベルが3Dモデル上に表示されます。
4. 3Dラベルまたは左上の工程をタップすると、対象が黄色で強調され、ラベルが拡大して推奨工具と工具イメージを確認できます。
5. 断面を確認する場合は、切断軸と切断位置を指定します。

「形状解析」と「差分比較」を切り替えると、誤って前のモデルを使わないよう、移動先の画面は未読み込み状態にリセットされます。

### 差分比較の使い方

1. 上部の「差分比較」を選択します。
2. 加工前（Before）と加工後（After）のSTEPファイルを選択します。
3. 「Before」「Diff Overlay」「After」を切り替えて形状を確認します。
4. 必要に応じて断面軸と切断位置を指定します。

差分比較は形状ブーリアン差分ではなく、同一座標系でのメッシュ重畳と外形寸法差による視覚確認です。


### CADデータの座標関係を崩さない
今回、特に気をつけたのがモデルの位置関係です。

3Dビューアでは、見やすくするためにモデルを自動的に中央へ移動したり、表示サイズを調整したりすることがあります。

しかし比較用途では、それをモデルごとに行ってしまうと本来の位置関係が分からなくなります。

そこでSTEP DIFF VIEWでは、読み込んだ2つのモデルの座標関係を維持したまま比較することを基本方針にしています。

見栄えよりも、比較ツールとしての一貫性を優先しました。

まずはベータ版として公開します
まだ検証段階なので、完成品ではありません。
むしろ今回公開する目的の一つは、

現場で「実際のSTEPデータを入れたとき、どこまで使えるのか」
を確認することです。

アプリにはデモデータを用意しています。STEPファイルをお持ちでない方でも、インストール後すぐに3D表示とDiff Overlayを試せます。
