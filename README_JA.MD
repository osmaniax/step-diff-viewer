## 【Androidベータ版公開】3D CAD（STEP）ビューワ「STEP DIFF VIEWER」をベータリリースします


### STEP DIFF VIEWERとは？
Androidスマートフォン上でSTEPファイルを読み込み、加工前後など2つの3D形状を比較できる軽量ビューアです。

今回公開した「STEP DIFF VIEWER」の操作画面です。

目指したのは、高機能なCADソフトの代替ではありません。

「PCでCADソフトを立ち上げるほどではない。でも、手元ですぐ形状を確認したい」

そんな場面で使える、小さなツールです。

### STEP DIFF VIEWでできること
基本機能はかなりシンプルです。

#### Before
![画面イメージ](./img/Screenshot_20260811-212334.png)

加工前など、比較元となるSTEPモデルを表示します。

#### Diff Overlay
![画面イメージ](./img/Screenshot_20260811-212336.png)

2つのSTEPモデルを色分けして重ね合わせ、形状の違いを視覚的に確認します。

ここは重要なのですが、厳密な幾何差分を計算して「削られた領域」を算出しているわけではありません。

2つの形状を同一座標系上で重畳表示することで、

「どこが変わったのか」

を直感的に確認するための機能です。

#### After
![画面イメージ](./img/Screenshot_20260811-212339.png)

比較先となるSTEPモデルを単独表示します。

画面も、

Before → Diff Overlay → After

の順番にしました。加工前を見る。違いを見る。加工後を見る。

余計な操作を覚えなくても、この流れで確認できることを優先しています。

### CADデータの座標関係を崩さない
今回、特に気をつけたのがモデルの位置関係です。

3Dビューアでは、見やすくするためにモデルを自動的に中央へ移動したり、表示サイズを調整したりすることがあります。

しかし比較用途では、それをモデルごとに行ってしまうと本来の位置関係が分からなくなります。

そこでSTEP DIFF VIEWでは、読み込んだ2つのモデルの座標関係を維持したまま比較することを基本方針にしています。

見栄えよりも、比較ツールとしての一貫性を優先しました。

まずはベータ版として公開します
まだ検証段階なので、完成品ではありません。
むしろ今回公開する目的の一つは、

現場で「実際のSTEPデータを入れたとき、どこまで使えるのか」
を確認することです。

アプリにはデモデータを用意しています。STEPファイルをお持ちでない方でも、インストール後すぐに3D表示とDiff Overlayを試せます。

### STEP DIFF VIEW （ベータ版）

対応OS：Android 16（その他のバージョンは未検証）  
動作確認端末：Pixel 10 Pro Fold  
対応形式：STEP（.step / .stp）  
料金：無料（ベータ版）  

実際のSTEPデータで、

「これは表示できた」
「このモデルは重かった」
「こういう比較ができると現場で便利」

といったフィードバックがあれば、今後の改善材料にしたいと思っています。
